## AboutMe
Vježba projekt. Klon AboutYou platforme za online kupovinu odjeće i modnih dodataka.

## Što radi

- Pregled i pretraga proizvoda po kategorijama i podkategorijama
- Korisnički računi i autentikacija
- Košarica i proces narudžbe
- Pretraga po nazivu proizvoda

## Tech stack

- Java / Spring Boot
- JWT autentikacija
- PostgreSQL

## Napomena

Projekt rađen u edukativne svrhe kao replika AboutYou e-commerce platforme.
